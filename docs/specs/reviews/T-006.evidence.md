## Desvios e observações
- **Aviso do Node 26 no build:** `ExperimentalWarning: localStorage is not available because --localstorage-file was not provided.` Não é erro; registrado no README e na `docs/versoes.md`.
- **Aviso do npm 11 sobre scripts de instalação:** `core-js@3.51.0 (postinstall ...)` não roda porque o npm 11 só roda scripts de instalação aprovados. O script do `core-js` só imprime uma mensagem; o build não depende dele.
- **Fundo escuro no painel do app:** no painel de navegador do app, o texto do site aparece escuro sobre fundo preto. O site está no tema claro (`color-scheme: light`, `--ifm-background-color: transparent`), e o painel pinta o fundo transparente de preto; num navegador comum o fundo é branco. Nada foi alterado.
- **`.gitignore`:** as regras globais `node_modules/`, `build/` e `.docusaurus/` já cobriam a pasta `site/`; as três linhas `site/...` do contrato foram acrescentadas mesmo assim.
- **Formatação pelo Prettier:** o `eslint.config.mjs` ficou com 4 espaços e os `.ts` com 2, por causa do `.editorconfig` da raiz, que o Prettier lê.
